# Fluent Lab · English Practice Workbench

English · [中文文档](README.md)

Fluent Lab is a private, local-first system for practicing English. It requires no account, API key, SQLite database, or cloud service. Every practice session is stored as ordinary files that you can open, search, copy, and back up yourself.

## Start in 30 seconds

1. Keep the whole project folder together instead of opening only the HTML file.
2. On macOS, double-click `start.command`. If macOS blocks it the first time, right-click it and choose **Open**. You can also run:

   ```bash
   cd ~/Downloads/fluent-lab
   ./start.command
   ```

3. Open `http://127.0.0.1:8765/` in your browser. To start the server manually, run this from the project root:

   ```bash
   python3 server.py
   ```

4. Allow microphone access, click the red round button to begin recording, and click it again to stop. Remember to click **Save this recording**. The page confirms when the files have been archived.

> Start Fluent Lab with `start.command` or `python3 server.py`. Opening `index.html` directly, or serving it with a plain `python3 -m http.server`, cannot save files into `recordings/`. The server listens only on `127.0.0.1` by default, so the site and recordings are not automatically uploaded anywhere.

## The recordings folder is the database

Every saved session is written under the project's `recordings/` directory:

```text
recordings/
  index.json
  2026-11-01/
    1793560000000-abcd1234/
      media.webm          # May also be media.m4a, media.mp4, or media.wav
      before.txt          # Original Muse / Whisper ASR transcript
      after.txt           # Typeless or manually corrected transcript
      prompt.txt
      corrections.md      # Error tags, main issue, natural phrasing, next step, self-review
      session.json        # Complete structured metadata
```

These files are the durable archive. You can inspect them directly, search them with normal tools, copy them to another computer, or back them up with Time Machine. The browser also keeps a fast IndexedDB cache. If that cache is cleared, starting Fluent Lab again rebuilds the session list and text from `recordings/`.

Deleting a session from the app moves its directory to `recordings/.trash/` instead of permanently erasing it immediately.

## Unlimited repeat-practice trees

Click **↻ Practice again** under any item in the session archive:

1. Fluent Lab brings the original prompt, purpose, and title back to the recording area and labels the new attempt as Take 2, Take 3, and so on.
2. Record or import media and save it. The new attempt appears below the session it repeats.
3. You can repeat any child attempt again. Both the depth and the number of attempts are unlimited.
4. Every attempt has its own media, `before.txt`, `after.txt`, `corrections.md`, and `session.json`.

The logical relationship is stored in `parentId`, `rootId`, `takeNumber`, and `repeatDepth` inside `session.json`. The same fields are included in `recordings/index.json` and CSV exports. Existing sessions need no migration and are treated as Take 1. Deleting a parent moves its full descendant tree to `.trash/`, preventing orphaned attempts.

## Suggested daily workflow

| Stage | Time | Practice |
|---|---:|---|
| Grammar | 7 min | Correct 3–5 real mistakes from yesterday's spontaneous speech |
| Chunks | 7 min | Recall whole English phrases from Chinese prompts, then add three new ones |
| Compression writing | 5 min | Express one idea in 100, 50, then 25 words |
| Speaking | 8 min | Speak in English for 90 seconds without interrupting yourself; save the original audio |
| Reflection | 3 min | Record what worked, where you got stuck, and one improvement for tomorrow |

After a session, open **Session Archive → View / Review**:

- Keep the original transcript, including real pauses, repetition, and grammar mistakes.
- Paste the Typeless or manually polished version into **After**.
- Mark A / B / C categories and specific grammar errors.
- Write one natural English alternative.
- Optionally create a Chinese-to-English spaced-repetition card.
- Optionally add your own six-dimension self-assessment. Scores are not generated by AI.

The archive can be searched and grouped by date or practice purpose. It also contains a daily training-journal history. Audio, Before, After, and review notes are stored on disk and cached in the browser.

## In-browser shortcut

Press **Option + Shift + R** on macOS, or **Alt + Shift + R** on Windows/Linux, to start or stop recording while the page is active. This combination avoids common browser hard-refresh shortcuts. If another application already uses it, click the red recording button instead.

## macOS global recording shortcut (optional)

A normal webpage cannot register a system-wide hotkey across applications. Fluent Lab therefore includes an optional Hammerspoon + FFmpeg workflow that records even when the browser is not focused.

### Test the recorder from the command line

```bash
brew install ffmpeg
./tools/quick-record.sh speaking    # Start
./tools/quick-record.sh speaking    # Run again to stop and save
```

The default destination is this project's `recordings/` directory, using the same archive format as browser recordings:

```text
fluent-lab/recordings/
  2026-10-27/
    2026-10-27_182301_speaking/
      media.m4a
      before.txt
      after.txt
      corrections.md
      session.json
```

Supported purposes are `speaking`, `grammar`, `chunks`, `compression`, `interview`, `reflection`, and `other`. Set `FLUENT_LAB_RECORDINGS` to use a different archive directory.

The script uses the default macOS audio input. The first run may require microphone permission for Terminal or Hammerspoon under **System Settings → Privacy & Security → Microphone**. If recording fails, inspect `recordings/.last-recording.log`.

### Register system-wide hotkeys

1. Install [Hammerspoon](https://www.hammerspoon.org/), for example with `brew install --cask hammerspoon`.
2. Move the complete project to `~/FluentLab/`, so the recorder path becomes `~/FluentLab/tools/quick-record.sh`, or edit the path in the Lua configuration.
3. Append the contents of `tools/hammerspoon-init.lua` to `~/.hammerspoon/init.lua`. Do not overwrite an existing configuration.
4. In Hammerspoon, choose **Open Config → Reload Config**. Grant Accessibility permission and, if needed, microphone permission.

| Global hotkey | Action |
|---|---|
| Command + Option + Shift + R | Start / stop a Speaking recording |
| Command + Option + Shift + G | Start / stop a Grammar recording |
| Command + Option + Shift + C | Start / stop a Compression recording |
| Command + Option + Shift + I | Start / stop an Interview recording |

Press the same shortcut twice to stop and save. The absolute path of the saved file is copied to the clipboard. Refresh or reopen Fluent Lab to see the new recording; no manual import is required.

## Optional local whisper.cpp transcription

If `whisper-cli` and a whisper.cpp model are already installed, run:

```bash
./tools/transcribe-local.sh ./recordings/2026-10-27/2026-10-27_182301_speaking/media.m4a
```

The default model path is `~/whisper.cpp/models/ggml-medium.en.bin`, and the script calls `whisper-cli` from your `PATH`. When the input is a session's `media.*` file, the transcript is written directly to that session's `before.txt`; refresh the app to see it. Other input files receive a neighboring `.txt` file. Set `WHISPER_MODEL` to choose another model.

This step is optional. The webpage does not automatically invoke Whisper. If Muse produces ASR immediately after you drop in the audio, paste that transcript into **Before** instead.

## Storage, backups, and privacy

- Each session's media, Before, After, and review notes live under `recordings/`; IndexedDB is only the browser's fast cache.
- There are no user accounts or built-in cloud sync. Copy the project—especially `recordings/`—to migrate it.
- `recordings/` is excluded by `.gitignore`, so Git commits do not back up private recordings. Use Time Machine, an encrypted drive, or another trusted backup location.
- **Data and settings** can export a complete JSON backup including browser-stored recordings. It may be large and contain private audio, so store it securely.
- A lightweight JSON export excludes audio and will not pretend the audio still exists when restored.
- CSV exports include text, dates, purposes, error tags, scores, and repeat relationships, but not media.
- Importing JSON replaces the browser cache; it does not automatically delete files already in `recordings/`.
- Fluent Lab does not provide AI scoring. All scores are manual self-assessments.
- An unsaved temporary browser recording is lost if the page is refreshed.
